# Map CSV & Tilemap Rendering

## Goal
Transition the game's level building away from hardcoded entity spawns to a data-driven Tilemap parsed from CSV files generated by tools like Tiled, allowing for rapid level design iteration.

## Proposed Changes

### 1. CSV Parsing Logic
**[MODIFY] include/Core/LevelManager.h & src/Core/LevelManager.cpp**
- Create an internal 2D array or vector `std::vector<std::vector<int>> mapGrid;` to store tile IDs.
- Write a CSV parsing loop inside `LoadLevel(const std::string& csvPath)`:
  - Open the file using `std::ifstream`.
  - Read line by line using `std::getline`.
  - Split each line by commas `,`.
  - Convert the string tokens to integers using `std::stoi` and push them into `mapGrid`.

### 2. Rendering the Tilemap
- Load the master tileset sprite sheet (e.g., `assets/tileset/Galra_ship-Sheet.png`).
- In `DrawLevel()`:
  - Iterate through `mapGrid` by row and column.
  - Multiply the row/column by the tile size (e.g., `32.0f`) to calculate the world space `(X, Y)` position.
  - Based on the tile ID, calculate the source rectangle from the sprite sheet and use `DrawTextureRec()` to draw it at the world position.

### 3. Grid-Based Collision
- Implement `bool IsSolidCollision(Rectangle box) const` inside `LevelManager`.
- Instead of checking collision against every object in the level, map the corners of the given `Rectangle` to row/col indices using integer division by `32`.
- Check if the corresponding `mapGrid[row][col]` contains a solid tile ID (e.g., wall IDs). Return true if a collision is detected.
- This allows `Player` and `Enemy` states to slide along walls by checking their next frame's position against the tilemap in `O(1)` time.

## Verification Plan
### Automated Tests
- Validate that `LoadLevel` does not crash if the CSV is missing (should gracefully exit or print an error).

### Manual Verification
- Walk around the map and verify the floor and walls render according to the CSV grid.
- Attempt to walk into walls to ensure `IsSolidCollision` correctly prevents the player from passing through.
