# Implementation Plan: Modular Level & Tilemap System

We will implement a Macro/Micro layout architecture similar to Soul Knight to transition the game from monolithic maps to procedurally arranged, discrete rooms.

## 1. Directory & File Structure
We will create a new directory for Level structural components:
- `include/Core/Level/RoomNode.h`
- `src/Core/Level/RoomNode.cpp`
- `include/Core/Level/Tilemap.h`
- `src/Core/Level/Tilemap.cpp`

## 2. Macro Layout: Level Graph
We will introduce `RoomNode` and `LevelMap` to define the overall dungeon flow.
- **`RoomType` Enum:** `SPAWN`, `BATTLE`, `CHEST`, `BOSS`.
- **`RoomNode` Class:** Holds grid positions `(gridX, gridY)`, four directional pointers (`north`, `south`, `east`, `west`), and state flags (`isDiscovered`, `isCleared`).
- **`LevelMap` Class:** Manages a 2D matrix/graph of `RoomNode` objects.

## 3. Micro Layout: Room Templates
We will create a `RoomTemplate` class to define the interior grid of each room.
- **Layer 0 (Environment):** 2D matrix mapping `0` (floor), `1` (wall), `2` (pit).
- **Layer 1 (Entities):** 2D matrix mapping `10` (player spawn), `20` (doors), `30` (enemy spawn), `40` (destructible crates).
- **Collision Generation:** `RoomTemplate::GenerateWallColliders(...)` will iterate through Layer 0 and return a `std::vector<Rectangle>` containing world-space colliders for all tiles marked as `1` (wall).

## 4. Rendering Pipeline
We will implement a stateless `TilemapRenderer` class.
- **`DrawRoom(const RoomTemplate& room, Vector2 roomOffsetWorldPos, Texture2D tileset)`:**
  - Iterates through Layer 0 and Layer 1 matrices.
  - Resolves textures via the provided tileset.
  - Enforces `SetTextureFilter(tileset, TEXTURE_FILTER_POINT)`.
  - Maps positions by wrapping coordinates in integer bounds using `std::floor(pos.x * Constants::GLOBAL_SCALE)` to prevent sub-pixel visual artifacts and tile bleeding.

## 5. Physics Integration
- In `LevelManager.h`, we will add support to hold an active `RoomTemplate`.
- We will cache the active room's walls: `std::vector<Rectangle> currentRoomWalls`.
- We will rewrite `LevelManager::IsSolidCollision` to iterate over `currentRoomWalls` and perform a standard `CheckCollisionRecs(box, wallRect)` using the existing feet-based hitboxes implemented earlier.

## Verification Plan
1. Create a hardcoded 1x1 test `LevelMap` using a static `RoomTemplate` representing the spawn room.
2. Verify that the `TilemapRenderer` successfully renders the room without grid artifacts at `Constants::GLOBAL_SCALE`.
3. Verify that the player's movement accurately bumps against the walls generated by `GenerateWallColliders`.
